# Kit 003 — Modular Gaming + Streaming Station
Date: November 13, 2026
Status: Public concept draft v0.1. Not assembled, benchmarked, priced, or available for booking.
Origin: Founder-defined concept; AI-assisted organization and critical review.

## Purpose
Explore an indoor gaming PC station with streaming peripherals. The founder described a “fishbowl” PC: interpreted here as a panoramic display-style desktop enclosure, subject to confirmation and transport testing. “CPU” in the spoken description is treated as a complete PC rather than only its processor.

## Proposed modular inventory
| Module | Draft scope | Unresolved |
|---|---|---|
| Compute | One gaming desktop in the proposed display-style enclosure | CPU, GPU, memory, storage, cooling, dimensions and weight |
| Display | One primary gaming display; additional display optional | Resolution, refresh rate, connectors and case fit |
| Input | Keyboard, mouse, headset; controllers if the selected activity needs them | Compatibility and accessibility |
| Streaming | Microphone, camera and suitable capture path | Software, platform, connectivity, consent and actual encoding load |
| Capture | Internal game capture or external capture device as needed | Avoid buying a capture card unless the signal path requires one |
| Transport | Protective cases, secured components, cable kit | Glass protection, GPU support and repeated deployment durability |
| Session | Selected games and a local recording rehearsal | Rights, account access, reset and guest data handling |

The transparent enclosure is an aesthetic proposal, not proof of portability. Compare a more robust compact enclosure if repeated transport, heat, packing or handling tests fail.
No viewer count, frame rate, resolution, stream quality or session capacity is promised.

## Example session to rehearse
Use an authorized game and operator-controlled test account. Unpack, connect, run a representative game, create a short local test recording, review game responsiveness and audio, save or delete the sample, reset the account/session, and repack.
Public streaming is a separate step after connectivity and permissions are resolved; no guest is broadcast by default.

## Proposed acceptance record
Record setup/reset/packing time, carried weight, enclosure and component security, measured electrical load, sustained temperature behavior, game responsiveness while recording, audio clarity, recording playback, and clean account reset. Define pass criteria around the actual chosen experience before promising performance.
A second monitor or extra controller does not establish simultaneous capacity. Shared equipment across kits must have a single booking allocation.

## Relationship and sequence
003 is an indoor alternative alongside 002, while 001 retains astronomy/astrophotography and gaming. Indoor operation reduces dependence on the observing conditions required by 001; it does not remove venue, funding, internet or staffing dependencies.
Define the offer and full shopping list, quote and fund it, assemble and test, then approach existing venues. Concurrent design is not a commitment to simultaneous purchases or events. A trailer or dedicated site is a separate later concept, outside this draft.

## Visual identity — proposed
Theme: **The Arena**. Graphite, deep crimson and controlled amber/gold accents. A display-style gaming PC, clean monitor and neatly arranged streaming peripherals. If used, the golden ant keeps the practical hoodie/headset and adult build. Images must say CONCEPT.
Public invitation: “Would you use a portable station to play, stream, or learn the setup?”
